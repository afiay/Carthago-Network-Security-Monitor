### Exact source boundaries, validation and data minimization

- **TDS 7.x:** one 8–4096-byte plaintext TDS packet, exact big-endian declared length, supported type subset `01/03/04/06/07/0E/10/11/12`, bounded status mask, reserved window zero, ATTENTION exactly 8 bytes, other types require body. The 4096-byte ceiling is conservative **pre-negotiation**; larger negotiated packets are deferred, not malformed in general. EOM is only the header bit, not proof of a complete SQL message. PRELOGIN `0x12` can encapsulate opaque TLS negotiation; no token, SQL text, login or query data retained. TDS 8.0 TLS-first remains opaque.
- **OpenFlow 1.3:** one 8–4096-byte complete plaintext TCP message, exact big-endian length and wire version `0x04`; recognized subset HELLO, ERROR (minimum 12), ECHO request/reply, FEATURES/GET_CONFIG requests, FLOW_MOD (minimum 56), multipart request/reply (minimum 16), BARRIER request/reply. Other versions, types, longer messages and bodies are not validated. Transaction XID and body omitted from observation. `ClaimedFlowModification` is a header **type** only, never an applied flow.
- **BFD v1:** one 24–64-byte complete UDP Control datagram; version 1, exact one-byte declared length, nonzero multiplier, My Discriminator and desired transmit interval, valid discriminator for Init/Up, no multipoint bit or simultaneous Poll/Final. Without authentication: exactly 24 bytes. With authentication: known RFC 5880 type/length envelopes only (simple password 4–19, MD5 24, SHA1 28); authentication **never checked**, keys/digests not retained. No BFD Echo or state-machine verification. RFC 5881 single-hop destination UDP/3784, source ephemeral port and TTL/hop-limit 255 are **upstream producer requirements**, not inferred from this payload parser.

All inspectors are stateless, deterministic, bounded and allocation-free in their parsing path, with no timers, network access, persistence, UI, alerts or sinks. Caller-supplied `verifiedComplete...` flags are **preconditions, not authentication**. Spoofed headers, shared-port traffic, misidentified endpoints and untrusted adapters remain false-positive risks. Privacy-sensitive payloads, transaction IDs, SQL text, BFD discriminators, authentication bytes and OpenFlow flow contents are not retained.
