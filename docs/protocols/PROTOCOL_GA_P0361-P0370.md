## P0362 isolated source contract and limits

- [Inspector](../../Carthago/Services/ProtocolIntelligence/SomeIpSdEnvelopeInspector.cs) and [authored xUnit scenarios](../../Carthago.Tests/ProtocolIntelligence/SomeIpSdEnvelopeInspectorTests.cs) are **protocol-stream-owned**. The SDK-style [application](../../Carthago/Carthago.csproj) and [test](../../Carthago.Tests/Carthago.Tests.csproj) projects use default compile inclusion; neither was edited. No new packages or external source copies.
- Strict complete, unfragmented **UDP** datagram, plaintext, verified SOME/IP-SD endpoint and capture-provenance booleans supplied by a trusted future caller. No current runtime caller exists. **Maximum 4,096 bytes; 64 entries; 64 options**; exact SOME/IP declared length; exact SD entry/option boundaries; fixed 16-byte entries; bounded option length and known endpoint-option shape; option-index-range checks; strict message/service/version/reserved bits. Rejects SOME/IP-TP, malformed lengths and unknown entry types. Opaque configuration/unknown option bodies are skipped within bounds.
- Output is limited to unverified operation counts and flags. It retains **no raw payload, ECU/service/session IDs, IP/MAC addresses, endpoint ports, credential, configuration strings or option contents**. Stateless and deterministic: no flow cache, TTL state, replay verdict, authentication, ECU authority or receiver outcome. “Offer” and “StopOffer” are **message shapes only**.
- This is **not** an inspector for the general SOME/IP TCP transport. A short malicious TCP message with an oversized declared length is outside the attested UDP-SD contract; no CVE-2026-91141 detection claim.
- No direct alerts, DetectionEvents, UI/sink calls, policy changes or journal writes. Existing JSONL-journal-first event provenance, immutable raw DetectionEvents, Shadow/Disabled, cooldowns, confidence floors, suppression reasons and holdouts are unchanged.
