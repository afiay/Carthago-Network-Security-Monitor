### Exact source profiles, limits and trusted fields

- **Portmapper v2:** exactly one 40–2048-byte RPC v2 CALL; program 100000/version 2; procedures NULL, SET, UNSET, GETPORT, DUMP only; two bounded XDR opaque-auth fields, each at most 400 bytes with strict zero padding; SET/UNSET/GETPORT require 16-byte mapping arguments. CALLIT (5), replies, RPCSEC_GSS interpretation and TCP record-marker parsing are unsupported. Exposes only procedure, requested program/version/protocol/port and message length. XID, auth flavors/bytes and credentials not retained. Caller-supplied transport/boundary is **not authenticated** by this inspector.
- **Cassandra CQL v4:** exactly one 9–16384-byte version 4 frame; big-endian body length must equal supplied bytes; request/response opcode and stream-direction checks, bounded flags, no compressed STARTUP; no v5 envelope framing, body validation, query parsing, stream-ID retention or decompression. Compressed body is **opaque**. Exposes opcode, direction, header flags and frame length only. TLS payloads are **NOT OBSERVABLE**.
- **Couchbase KV:** exactly one 24–16408-byte classic/flexible binary envelope; validates magic, selected opcodes, data type bits, body/extras/key/framing lengths and up to 32 flexible FrameInfo items; a strict subset of GET/SET/DELETE request shapes. Generic Memcached wire compatibility prevents product identification without a trusted endpoint. Exposes opcode, direction, framing mode, key/value lengths, total length and **claimed** response status only; no success/authentication assertion. Keys, values, bucket names, SASL, opaque correlation IDs, CAS and framing data not retained. TLS payloads are **NOT OBSERVABLE**.

All three inspectors are stateless, deterministic, finite, allocation-free for their parsing path and do not emit events, alerts, UI messages, logs or external sinks. The typed observations do **not** certify the caller's claimed provenance. False positives remain possible if a caller falsely attests plaintext, boundaries, transport or endpoint identity.
