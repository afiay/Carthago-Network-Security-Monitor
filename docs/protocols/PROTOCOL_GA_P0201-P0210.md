| **P0207 `fcdns`** — Fibre Channel Name Server | **BLOCKED — NATIVE FC INPUT** | Fibre Channel generic-services name-server function; no FC frame or FCoE-decapsulated, provenance-preserving producer. | **P0208 `fcs`** — Fibre Channel Fabric Configuration Server | **BLOCKED — NATIVE FC INPUT** | FC fabric-configuration service requires attested FC fabric frames and switch audit; no such source in PacketHandler/ETW/Cisco adapters. | **P0210 `mgmt`** — DCE/RPC Remote Management | **REJECTED_DUPLICATE_OR_NOT_A_PROTOCOL** (RPC interface/subdissector) | Not a new L4 protocol; reuse DCE/RPC framing tracked as P0012.
