The two new C# source files and three test files are auto-included without changing either .csproj. No matching MQTT-SN/RTP/RTCP inspector was present in the protocol-owned folder at this base.

[PacketHandler](../../Carthago/Services/PacketHandler.cs) accepts IPv4/IPv6 after Ethernet/VLAN framing, drops non-IP and unsupported final L4 protocols, and does not provide a verified complete plaintext datagram/protocol registration to these new inspectors. UDP payload availability does not itself prove capture completeness, media association, nonfragmentation or provenance. No authenticated endpoint, proxy, relay or switch producer is established by the current parser. Existing service labels are hints, not decoders. **The new source is ISOLATED — NOT LIVE-CAPTURE INTEGRATED.**

**MQTT-SN:** 2–4096 bytes; exact canonical 1-octet length or 3-octet extended length (only for >255); validates only ADVERTISE, SEARCHGW, GWINFO, CONNECT (ProtocolId 1, restricted flags), CONNACK, PUBLISH (flags and fixed header), PINGREQ, PINGRESP, DISCONNECT. All other types fail closed, including subscription and encapsulation. No gateway identity, ClientId, topic, message body, return-code outcome, authenticated state or credentials retained. MQTT over TCP is not MQTT-SN; radio/Zigbee remains not observable without a separate approved adapter. The `verifiedCompletePlaintextDatagram` parameter is a **caller assertion**, not an independent trust mechanism.

**RTP:** 12–8192 bytes; version 2, bounded CSRC/extension words, padding, payload type and sequence number only. RTP marker+payload combinations whose second byte is 200–207 are conservatively rejected to avoid RTCP collisions, potentially rejecting legitimate RTP. No codec, media content, SSRC, timestamps, session association or cryptographic verification. **SRTP is NOT OBSERVABLE**. Single packet sequence does not establish loss/reorder, retransmission, impersonation or attack.

**RTCP:** 8–8192 bytes; at most 32 compound packets; first SR/RR, version 2, supported packet types 200–207, checked 32-bit word lengths, basic type-specific minimum sizes, last-packet-only padding. It does not decode SDES/CNAME, reception reports, source identity, full RTCP validity or reduced-size standalone feedback. **SRTCP is NOT OBSERVABLE**. A structurally valid RTCP report is not authenticated and not evidence of call disruption.

All three inspections are stateless, bounded, deterministic, `ReadOnlySpan<byte>`-based, no unbounded allocation, no regex or raw sensitive payload retention. They return immutable value observations and never generate DetectionEvents, alerts, journal entries, UI events or external sink output. R102/R118/R163 confidence floors, frozen R102 V1 4/6, V2 provenance, modes, cooldowns, suppression, privacy and journal-first raw event truth remain untouched.
