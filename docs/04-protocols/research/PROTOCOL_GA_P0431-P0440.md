## Ten consecutive source-grounded decisions

| Original ID / key / label | Disposition | Security value, required typed producer, legitimate alternative, source and reachability |
| --- | --- | --- |
| **P0431 `fcfzs` — Fibre Channel Fabric Zone Server** | **BLOCKED — NATIVE FC / TRUSTED SWITCH INPUT** | FC zoning management is real (FC-GS-5 Zone Server; [RFC 4936](https://www.rfc-editor.org/info/rfc4936) defines SNMP MIB objects). Unauthorized zone activation or membership change would require switch/fabric identity, trusted zone-set change event, actor/role, prior and resulting active configuration, and management-session outcome from an approved FC switch API/SNMP/syslog producer. Normal maintenance, migration and zoning edits are benign. Existing SNMP client is not a zone-change audit feed; no native FC CT frame producer. **NOT OBSERVABLE** as a live FC operation. |
| **P0432 `fddi` — Fiber Distributed Data Interface** | **BLOCKED — NATIVE FDDI LINKTYPE** | Genuine legacy LAN media/framing, not a TCP/UDP service. Rogue station or topology anomaly requires a native FDDI frame/link-state capture adapter with trusted station identity and change baseline; legitimate ring recovery produces similar events. Current packet path has no FDDI linktype and drops unknown link layers. No port-based decoder can substitute. |
| **P0433 `fldb` — DCE DFS Fileset Location Server** | **DEFERRED — DCE/RPC APPLICATION CONTRACT** | DCE DFS fileset-location application interface; reuse the existing isolated P0012 DCE/RPC header inspector, **not** a second generic RPC transport. Suspicious location-map mutation needs attested interface UUID/opnum, RPC authentication principal, fileset identity, server outcome and DFS audit logs. Legitimate relocation/failover is a strong negative. No deployed DFS service, trustworthy application fixture or authenticated outcome; no claim of operation decoding. |
| **P0434 `hci_usb` — Bluetooth HCI USB Transport** | **REJECTED_DUPLICATE_OR_NOT_A_PROTOCOL** | HCI-over-USB is a **transport binding/capture surface**, not an independent Bluetooth application protocol. Native USB HCI events would require a separate driver/USB producer with controller identity and trusted event provenance; no such input exists. Reuse the Bluetooth/HCI family instead of inflating distinct-protocol count. Controller resets, pairing and legitimate device changes must not be treated as attacks from the transport label. |
| **P0435 `lithionics_bms` — Lithionics Battery Management System** | **DEFERRED — VENDOR MEDIA AND FIXTURES** | A vendor-specific BMS dissector label, not proof of a deployed IP service. Possible unsafe control/state anomalies require the vendor's authorized protocol framing, physical transport/adapter, battery identity, command vs telemetry distinction, validated status, and safety/maintenance context. Normal charge cycles and service actions can resemble anomalies. No trustworthy capture producer, supported media or licensed fixtures; no speculative parser. |
| **P0436 `lmi` — Local Management Interface** | **BLOCKED — FRAME RELAY INPUT** | Frame Relay PVC/link-management signaling ([Cisco ASR 9000 reference](https://www.cisco.com/c/en/us/td/docs/routers/asr9000/software/interfaces/command/reference/b-interfaces-hardware-component-cr-asr9000/frame-relay-commands.html), ANSI T1.617 Annex D / ITU-T Q.933 Annex A). Unexpected PVC state or keepalive changes need native Frame Relay/DLCI framing, DTE/DCE role, interface status and device audit. Routine circuit recovery is benign. No Frame Relay linktype/producer; IP port inference is invalid. |
| **P0437 `lnpdqp` — Local Number Portability Database Query** | **DEFERRED — TELECOM DEPLOYMENT / SPECIFICATION** | Query-protocol candidate for portability databases, not independently validated by the Wireshark label alone. Enumeration or unauthorized lookup would need verified protocol specification, trusted requestor/tenant, query rate, access policy and authoritative server audit/outcome; legitimate bulk portability operations are expected. No confirmed local deployment, wire framing, endpoint logs or approved privacy treatment for subscriber numbers. |
| **P0438 `mplstp_fm` — MPLS-TP Fault-Management** | **BLOCKED — MPLS OAM INPUT** | Genuine fault-management OAM message family, **not** a wholly separate new transport ([RFC 6427](https://www.rfc-editor.org/info/rfc6427), November 2011; updated by RFC 7214). Spoofed lock/fault indications need trusted MPLS label stack/G-ACh framing, maintenance entity/MEP identity, operator intent and actual LSP state from router telemetry. Real outages and planned maintenance are benign. No MPLS/G-ACh producer; no false fault/suppression detection. |
| **P0439 `mtp3mg` — Message Transfer Part Level 3 Management** | **BLOCKED — SS7 / SIGTRAN PRODUCER** | MTP3 network-management subfamily; not independently counted as another generic IP protocol. False route unavailability/congestion needs attested SS7 signaling link or SCTP/M3UA association, point-code and management message type, peer identity, and switch state ([RFC 4666](https://www.rfc-editor.org/info/rfc4666), September 2006, defines M3UA interworking). Genuine network failures and failover look similar. No native SS7 link or validated SCTP/M3UA producer; generic IP capture does not prove these operations. |
| **P0440 `ndps` — Novell Distributed Print System** | **DEFERRED — LEGACY PRINT DEPLOYMENT** | Genuine legacy distributed-print service family, potentially IPX or IP-based ([Novell NetWare 6 NDPS](https://www.novell.com/documentation/nw6p/ndps_enu/data/h6ajgkbr.html)). Unauthorized print-job/driver changes require trusted print manager/agent logs, principal, job metadata with redaction, printer identity and server outcome. Routine driver installs and queue administration are benign. No confirmed deployed NetWare/NDPS assets or validated message source; not equivalent to IPP or a port hint. |

## Integration proposal — NOT APPROVED / NOT APPLIED

A separate owner-approved coordination GA would first add an optional, explicitly enabled source adapter for each native medium (FC, FDDI, USB HCI, Frame Relay, MPLS/G-ACh, SS7/SCTP), or authenticated vendor audit integration where appropriate. Minimal proposed producer contract: source kind and immutable capture provenance, linktype/transport, bounded complete frame or PDU boundary, trusted asset/peer and direction, observation timestamp, producer trust tier and redaction policy; **no automatic DetectionEvent**. For DCE/NDPS, add verified application identity/UUID, authorization and outcome only from attested server logs. Consumers must fail closed when provenance or framing is missing. Compatibility scenarios: supported and unknown linktypes, malformed/truncated and overlong frames, duplicate/out-of-order messages, legitimate maintenance, spoofed origin, opaque/privileged data redaction, no fabricated successful action, and original journal/serialization invariants. Rollback: disable and remove the optional adapter without changing the existing packet fast path, `TrafficRecord` schema, rule IDs, or UI. **Shared-core integration is BLOCKED pending explicit owner approval and a fresh overlap review.**
